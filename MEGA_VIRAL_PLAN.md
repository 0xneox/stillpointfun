## THE VISION

## PHASE 1: CORE DISCOURSE FEATURES (Weeks 1-4)

### 1.1 User System

- **Profiles** with bio, practice tradition, journey stage
- **Verification tiers**: Seeker → Practitioner → Guide → Teacher
- **Daily check-in**: "Where am I?" (mood, practice time, inquiry)
- **Practice tracking**: Sadhana journal, meditation timer
- **Achievement badges**: 7-day streak, 30-day retreat, etc.

### 1.2 Posting System

- **Inquiry posts**: Share a question or realization
- **Reflection posts**: Document a daily insight
- **Quote posts**: Share wisdom with personal commentary
- **Media posts**: Share talks, music, readings with discussion
- **Practice logs**: Document your sadhana/journey

### 1.3 Discussion Features

- **Threaded comments** (like Reddit but spiritual)
- **Upvote/downvote** based on depth/insight (not popularity)
- **Follow threads** to track conversations
- **Mention teachers/participants** (@username)
- **Reply notifications**
- **Bookmark/save posts**

### 1.4 Spaces/Rooms

- **General inquiry** - open satsang
- **Specific traditions** - Advaita, Zen, Sufi, Buddhist
- **Teacher spaces** - spaces for specific teachers
- **Local groups** - geographic satsang groups
- **Practice circles** - accountability groups
