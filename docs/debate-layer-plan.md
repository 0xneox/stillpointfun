# Deferred debate layer

The debate-map layer is deferred. It will be designed only after the Path and its supporting content are established. This plan does not add routes, UI, or debate content.

Each future map should have:

- **Question:** one clearly scoped question.
- **Positions per tradition:** distinct positions with each tradition and source identified; do not flatten differences into a synthetic consensus.
- **Objection and reply:** objections should address the stated position, and replies should answer those objections rather than changing the question.
- **Sources:** citations that identify source works and locations, with rights and provenance reviewed.
- **Disagreement note:** state where the sources or traditions genuinely disagree and where available material is incomplete.
- **Steelman rule:** represent each position in its strongest fair form before critique; do not caricature or silently merge positions.
